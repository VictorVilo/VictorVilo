## 👋 About Me

I'm a **Senior Software Engineer** based in Nairobi, currently working in financial services at **Equity Group**. I build the systems that move money: payment rails, wallets, transaction engines, KYC and authentication flows, plus the mobile and web products customers actually touch.

My work sits where **fintech, cloud architecture, and product engineering** meet. I'm happiest owning a system end to end, from API contract and data model to deployment, monitoring and the app in the user's hand.

## 🧩 Engineering Principles

> **Design for reliability.** Money systems don't get "mostly works." I build for idempotency, auditability and graceful failure.
>
> **Architect for scale.** Clear boundaries, observable services, and infrastructure that grows with the business.
>
> **Secure by default.** Security and compliance are part of the design, not a checklist at the end.
>
> **Ship with ownership.** From the database schema to the app store release, I own outcomes, not just tickets.
